# Store listing

F-Droid (#163) reads Koalino's listing from `metadata/android/<locale>/` in this layout:
`title.txt`, `short_description.txt`, `full_description.txt`, `images/icon.png` (512 px) and
`changelogs/<versionCode>.txt`. `images/icon.png` is generated by `branding/make-icons.sh` (#165).
