The "Context" Files: Create an ARCHITECTURE.md (high-level design), API_SPECS.md (gRPC/REST definitions), and CONTEXT.md (current state of the project, what is done, what is next). Feed these to the AI at the start of every session.
Test-Driven Development (TDD): You mentioned tests must pass before commit. Make the AI write the tests first. Prompt: "Write a failing test for the CRDT merge function. Then write the code to make it pass." This prevents the AI from writing hallucinated, untestable code.
Micro-commits: Never ask the AI to "build the P2P sync." Ask it to "implement the libp2p peer discovery for local LAN." Commit. Then "implement the mDNS broadcast." Commit.
