# Branding assets (`ui/assets/branding`)

`koalino.png` is Koalino's icon at 256 px, drawn by `KoalinoLogo`
(`lib/presentation/koalino_logo.dart`) in the navigation rail and the About dialog (#172).
`branding/make-icons.sh` generates it from `branding/koalino.svg`; rerun that script instead of
editing it here.
