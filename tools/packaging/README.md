# Packaging

`linux/` turns the Linux desktop tarball (`koalino-linux-x86_64-VERSION.tar.gz`) into
distribution packages (#164). Each script only repackages the release build; nothing is
compiled or downloaded.

| File | What it does |
| --- | --- |
| `linux/build-deb.sh` | `.deb` for Debian 13+ and Ubuntu 24.04+, with `dpkg-deb` |
| `linux/build-rpm.sh` | `.rpm` for Fedora, openSUSE and other RPM distributions, with `rpmbuild` |
| `linux/build-flatpak.sh` | single-file `.flatpak` bundle on the Freedesktop 24.08 runtime |
| `linux/io.github.capannone_dev.koalino.desktop` | menu entry; `StartupWMClass` is the GTK application ID, so the window gets the icon |
| `linux/io.github.capannone_dev.koalino.metainfo.xml` | AppStream description for software centres |
| `linux/io.github.capannone_dev.koalino.yml` | Flatpak manifest (the script fills in the tarball's path and SHA-256) |
| `linux/koalino-128.png`, `koalino-192.png`, `koalino.svg` | icons, generated by `branding/make-icons.sh` |

The `.deb` and `.rpm` install the app in `/opt/koalino`, `koalino` in `/usr/bin`, and the menu
entry, icons and AppStream file under `/usr/share`. Dependencies are the system libraries the
bundle does not carry: GTK 3, ALSA, libstdc++ and xdg-utils, plus a keychain as a
recommendation.
