# Static files (`browser-extension/static`)

Copied unchanged into `dist/firefox` and `dist/chromium`: `popup.html`, `options.html` (the settings page, #212),
`koalino.css` (the colour tokens both pages share, light and dark, matching the web dashboard) and the toolbar icons
(`icon-16.png` to `icon-128.png`, generated by `branding/make-icons.sh`). The popup's fixed text is English in the file; elements marked
`data-i18n` get the browser's language from `popup.ts` and `options.ts` (#124).
