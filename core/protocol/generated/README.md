# Generated protocol code (`core/protocol/generated`)

The Rust types that rust-protobuf 3.7.2 generates from `../teams_bridge.proto`. **Do not edit by
hand.** Regenerate with `NOTE_TAKER_REGENERATE_PROTOCOL=1 cargo test --lib
protocol::generated_code_tests`. Without that variable, the same test fails when these files no
longer match the schema. The code is checked in, rather than generated by a build script, so
the core builds without a code generator and the host build graph (and with it the native
whisper.cpp build) is unaffected. Only `adapters/network/teams_bridge/message_decoder.rs` uses
these types; the rest of the core sees domain values.
