# Platform icons

The logos beside each platform in the README's Download table. All but `windows.svg` come from
[Simple Icons](https://simpleicons.org/) 16.38.1 (CC0-1.0), filled with each brand's colour (grey
for Linux and Apple, whose black logos would vanish in dark mode). Simple Icons has no Microsoft
logos, so `windows.svg` is a plain four-pane window drawn for this project. The logos are the
trademarks of their owners and only name the platform each package is for.
