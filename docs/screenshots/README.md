# Screenshots (`docs/screenshots`)

The pictures in the main README (#125), taken on the test VMs from the 0.1.0 preview packages:
the Linux app and the server package's dashboard on Debian 13 (`deb-gui`), the Windows app on
Windows 11 (`win11`), and the browser extension's popup in Chromium.

The meeting shown is a five-minute excerpt (from minute 2) of meeting ES2004a of the
[AMI Meeting Corpus](https://groups.inf.ed.ac.uk/ami/corpus/), CC BY 4.0, imported with
`cli record start --input` and transcribed by Koalino. No real meetings appear here; keep it that
way when replacing a picture.
