# Website

Koalino's website (#166), published by `.github/workflows/pages.yml` at
<https://capannone-dev.github.io/koalino/> once the repository is public (#161).

- `index.html`: what Koalino does, the download table, and links to the source.
- `privacy.html`: the privacy policy the app stores and F-Droid link to (#127, #163). It must
  match what the apps store and send: update it with any change to that.
- `style.css`: the shared styles, light and dark.
- `koalino.svg`: the logo, copied by `branding/make-icons.sh`.

Plain HTML and CSS with no build step and nothing loaded from other sites. Preview it by opening
`index.html` in a browser.
